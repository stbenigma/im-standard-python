Code postal

*Division territoriale attribuée par la Poste. Dans de nombreux pays, le code postal n'est pas un chiffre mais une suite de chiffres et de lettres

Il existe des systèmes hiérarchiques pour la structure des codes postaux :
E. G. USA
221 - 62 -10 -10
Segment - secteur - service postal ou stade de distribution - zone d'acheminement ou centre de traitement et de distribution

Il peut exister d'autres systèmes standardisés
P3 : Code postal
P2 : Sous-région du code postal
P1 : Zone du code postal
P0 : Pays
